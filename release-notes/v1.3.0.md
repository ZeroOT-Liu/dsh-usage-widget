## 新增

### 当前时段：高峰还是空闲，一眼可见

以前只知道「今天花了多少」，但花费是按高峰／空闲两档算的，看不出现在这一刻按哪档计价。现在部件会直接告诉你在哪一档：

- **收起状态**：「今日」那一行前多了一个实时徽标 —— 高峰时是 `高峰时段 ×2`（警示色），空闲时是 `空闲时段`（弱化色），不展开也能看见。
- **展开面板**：余额下方新增「当前时段」一节，显示当前档位、高峰倍数，以及 `距切换 1h 30m → 空闲时段` 的倒计时，并附一行说明高峰时段的具体区间。
- **悬停提示**：窄栏（56px）收起时，时段信息也一并进入提示文本。

时段判定与计价共用同一份窗口定义，因此**显示的档位与算出的花费不可能不一致**。判定使用宿主时钟，两个时间点（当前时刻、下次切换时刻）随响应一起下发，所以浏览器处于任何时区、即使本机时钟不准，倒计时也依然正确。周末会正确跳到下一个交易日的第一个窗口。

### 配置

新增 `showWindow`（默认 `true`）：设为 `false` 只隐藏时段徽标与面板行，数字照旧显示。

```yaml
config:
  showWindow: true
```

## 验证

- 单元测试 27 项（新增 4 项时段窗口用例：盘内切换、午休与傍晚、跨周末跳转、边界分钟归属），客户端 11 项（新增「徽标可见并可用配置关闭」），宿主 9 项，共 **47 项**全部通过。
- 客户端用例在 Node 中以真实模块加载握手渲染部件，并断言徽标位于「今日」行、倒计时由宿主下发的时刻计算、`showWindow: false` 时徽标消失而数字保留。

## 安装

```bash
dsh plugin --profile desktop add "https://github.com/ZeroOT-Liu/dsh-usage-widget/releases/latest/download/dsh-usage-widget.tgz"
```

**升级后需要重启 Harness**（宿主半边只在进程启动时加载），然后刷新页面（Ctrl+R）。

> 部件端点新增了 `window` 与 `hostNow` 字段。新版客户端 + 旧版宿主会安全降级为「不显示徽标」，不会报错。
