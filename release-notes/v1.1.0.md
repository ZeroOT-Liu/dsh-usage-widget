## 新增

**插件图标** —— 在插件管理器的插件列表与设置页的插件清单里显示。

设计上要同时表达两件事：它是 **DeepSeek Harness** 的插件，它讲的是**用量**。所以标记由两部分组成——上方是 Harness 的**虎鲸尾鳍**（取自官方应用图标的形态，但只保留尾鳍，不做成官方标记的复刻），下方是**三根递增的柱**表示 token 消耗与统计。底色用 Harness 主题里的品牌蓝 `#4176e6`（`--dsw-alias-brand-primary-new-color`），到 `#5686fe` 的渐变，使它在浅色与深色主题下都成立。

图标是 SVG（[icon.svg](https://github.com/ZeroOT-Liu/dsh-usage-widget/blob/main/icon.svg)），在 16px–256px 下都保持清晰；`assets/icon.png` 是同一图形的 256px 位图版本，供 README 使用。

### 为什么侧边栏里的小图标没跟着换

侧边栏左下角那个图标只有 **16px** 且是单色。把它换成新的尾鳍 + 柱状标记实测会变糊（柱太细、尾鳍太小），可读性明显不如原来的钱包图标。所以两处各用各的：**插件图标**负责在列表里被认出来，**侧边栏图标**负责在 16px 下把这一行讲清楚。

## 安装

```bash
dsh plugin --profile desktop add "https://github.com/ZeroOT-Liu/dsh-usage-widget/releases/latest/download/dsh-usage-widget.tgz"
```

装好后刷新页面（Ctrl+R）。
