## 把信息密度调回来

上一版把收起行压成了一行，只留余额和今日花费，确实过头了 —— 「空闲时段」「今日消费」「本月消费」这几项是每天都会看的，不该藏起来。这一版把三行收回，同时保留上一版修好的排版与配色。

### 收起：三行，信息齐全

```
[▭] 余额 ¥5.83 · 赠送 ¥9.79
    ● 空闲时段 · 今日 ¥0.79
    本月 ¥0.79
```

- 第一行：充值余额为主色加粗，赠送余额以弱化色跟在后面
- 第二行：`● 空闲时段`（高峰时圆点转琥珀色）+ 今日花费
- 第三行：本月花费

和最初的版本比，同样是三行，但去掉了 `tokens` 单位与重复的 `余额/今日/本月` 标签拼接，数字改用等宽数字，行距与字号按层级重排，所以看起来不挤。

### 悬停：今日拆分

```
今日                    20.34M · ¥0.79
──────────────────────────────
输入 328.2K        输出 143.6K
缓存命中 19.86M    命中率 98%
● 空闲时段          3h 12m 后高峰
                        点击查看明细
```

只补「今日花到哪去了」，不再把按模型、本月、当前会话一次铺开。

### 点击：剩下的明细

请求数、本月 tokens、按模型（每个模型的 tokens 与花费）、当前会话、更新时间与版本、刷新。再点一次或 `Esc` 收起。

## 验证

- 客户端 **13 项**（改用例覆盖三行收起、悬停只出今日拆分、点击才出模型与会话、时段行可关闭）
- 宿主 **38 项**、冒烟 **9 项**，共 **60 项**全部通过
- 用真实 `client.js` 在浅色／深色两套主题 token 下离线渲染核对

## 安装

```bash
dsh plugin --profile desktop add "https://github.com/ZeroOT-Liu/dsh-usage-widget/releases/latest/download/dsh-usage-widget.tgz"
```

只改客户端半边，**刷新页面（Ctrl+R）即可**；若界面没变再重启 Harness。
