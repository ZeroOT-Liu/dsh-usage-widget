## 新增

- **本月累计** —— 本月至今的 tokens、花费、请求数、活跃天数与会话数。

  收起状态下现在是三行，关键数字都直接可读：

  ```
  余额 ¥5.83 · 赠送 ¥5.27
  今日 20.3M tokens · ¥1.3
  本月 221.3M tokens · ¥11.98
  ```

  展开面板新增「本月累计」区块（总 tokens、花费、请求数、活跃天数、会话数），当前会话区块也多了一行它自己的本月数字。

  月份边界按**本机时区**划分，和「今日」一致；月度是从已有的按日聚合里并出来的，不额外读取日志。

- **新增配置 `showMonth`**（默认 `true`）—— 设为 `false` 可以隐藏收起状态的本月那一行，让页脚保持两行。

## 关于完整性

本月累计依赖日志保留窗口。默认 `keepDays: 45` 足以覆盖一个自然月，此时合计是完整的；若把它调到 32 以下，月初的数据可能已被清理，面板会明确标注「本月早期数据超出保留窗口，可能不完整」，而不会把一个不完整的数字当成完整的展示。

## 验证

- 宿主测试扩到 18 项：新增月度聚合用例，覆盖跨天求和、跨月隔离、按会话过滤、保留窗口不足时的 `complete` 标记；并像「今日」一样，**与真实日志的全量解码做交叉验证**（本月 2 天 / 808 请求 / 2.21 亿 tokens / ¥11.98，逐字段一致）。
- 客户端测试扩到 10 项：收起三行、面板月度区块、当前会话本月数字、`showMonth: false` 时不显示该行。
- 三套测试共 37 项，全部通过，发布流水线同样运行。

## 安装

```bash
dsh plugin --profile desktop add "https://github.com/ZeroOT-Liu/dsh-usage-widget/releases/latest/download/dsh-usage-widget.tgz"
```

**升级后需要重启 Harness**（宿主半边的改动不会被热重载拾取），然后刷新页面（Ctrl+R）。
