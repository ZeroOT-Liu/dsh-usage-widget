首个版本：在 DeepSeek Harness 侧边栏左下角（Settings 上方）显示账号余额、今日 token 消耗与今日花费。

## 功能

- **账号余额** —— 通过官方账号服务 `ctx.deepseekAccount.getBalance` 读取，与「设置 → 账号」同源。充值余额与赠送余额都显示在**收起状态的第一行**，不需要展开。
- **今日 token 消耗** —— 全部会话合计，含输入（缓存命中 / 未命中）、输出与推理 token，并显示涉及会话数与请求数。
- **今日花费** —— 按官方价目表与**高峰 / 空闲时段**（北京时间，工作日 9:00–12:00、14:00–18:00 翻倍）换算。
- **悬停或点击展开** —— 余额、今日明细、按模型分组、当前会话今日明细、更新时间与刷新按钮。
- **窄栏适配** —— 侧边栏收起成 56px 轨道时缩为一个图标，完整数值在悬停提示里。

## 实现要点

- 会话日志是**多帧 Zstandard**（每批追加一帧），Node 的同步解压只吃第一帧。插件按帧边界扫描并**增量读取**，未写完的尾帧跳过、下一轮补上，因此不会重复计数。实测首轮扫描 287ms，之后每次约 4ms。
- 宿主只注册一个精确路由。它会优先于 API 网关的 `/api` 前缀匹配，因此该路由自行执行与网关同等的信任判定：仅接受回环 `Host`，拒绝跨站 `Origin`，其余一律 403。
- **零依赖**：只用 Node 内置模块与相对导入，样式仅引用 `--dsw-alias-*` 主题 token，客户端不 `require` 任何 Harness Client 包。

## 安装

```bash
dsh plugin --profile desktop add "https://github.com/ZeroOT-Liu/dsh-usage-widget/releases/latest/download/dsh-usage-widget.tgz"
```

装好后刷新页面（Ctrl+R）。

## 已知限制

- 花费是按价目表推算的参考值，**不是账单**；官方调价后需更新配置中的 `models`。
- 「今日」按宿主本机时区划分。
- 中国法定节假日不在高峰规则内，节假日按高峰计价。
