## 重新设计的界面

### 收起：只剩一行

以前收起状态挤了三行字：`余额 ¥5.83 · 赠送 ¥9.79`、`空闲时段 今日 20.34M tokens · ¥0.79`、`本月 20.34M tokens · ¥0.79`。数字重复、标签重复，页脚看起来像一张报表。

现在只有一行：**左边余额，右边今日花费**。

```
[▭] ¥5.83                    今日 ¥0.79
```

高峰时段时，今日花费左边会多一个很小的琥珀色圆点 —— 不占字，但能看出此刻按翻倍计价。

### 悬停：一张紧凑卡

以前鼠标放上去弹出的是一整面板：余额、时段、输入、缓存命中、输出、推理、花费、请求数、会话数、按模型、本月、当前会话……三十行左右，还带一段说明文字的换行。

现在悬停只给最关键的四个数：

```
余额                      ¥5.83
赠送                      ¥9.79
────────────────────────────
今日              20.34M · ¥0.79
● 空闲时段        3h 12m 后高峰
                        点击查看明细
```

余额用 20px 强调，其余按层级降级；赠送余额退到弱化色，不再和主余额抢位置。

### 点击：才展开明细

点一下卡片才会钉住并展开完整数据：

- **四宫格**：输入 / 输出 / 缓存命中 / 命中率 —— 从竖着一列改成了 2×2，扫一眼就能比较
- 本月、请求数
- 按模型（每个模型的 tokens 与花费）
- 当前会话
- 页脚：更新时间与版本号、刷新

再点一次收起，或按 `Esc`。

### 视觉

- 卡片改用 `--dsw-alias-bg-layer-2` 与 `--dsw-elevation-panel`，在浅色与深色主题下都与宿主一致
- 数字一律 `tabular-nums`，对齐不跳动；主数字加了 `letter-spacing: -0.02em`
- 分隔线只保留必要的两条，间距按 12px 内边距与 8px 节奏重排
- 卡片最高 `min(72vh, 460px)`，超出可滚动，不会顶出侧边栏

### 窄栏

侧边栏收成 56px 时仍是一个图标，但提示从五行压成**一行**：`余额 ¥5.83 · 今日 ¥0.79 · 展开侧边栏查看`。

## 验证

- 客户端 **13 项**（含新增的「收起只有一行」「悬停不出现完整明细」「点击才出现明细」「时段行可关闭」四项）
- 宿主 **38 项**、宿主冒烟 **9 项**，共 **60 项**全部通过
- 另外用真实 `client.js`（真实字典、真实样式表）在浅色／深色两套主题 token 下离线渲染截图核对，确认渲染结果与设计一致

## 安装

```bash
dsh plugin --profile desktop add "https://github.com/ZeroOT-Liu/dsh-usage-widget/releases/latest/download/dsh-usage-widget.tgz"
```

只改客户端半边，所以**刷新页面（Ctrl+R）即可**，不必重启 Harness。
